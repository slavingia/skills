# Gotchas — company-values

Common failure modes when helping define company values.

| Gotcha | Detail |
|--------|--------|
| Generic two-word slogans | "Be innovative" or "Work hard" — values should be non-obvious and sometimes polarizing. If it sounds like a motivational poster, it is not a value. |
| Values that don't differentiate | If any company could claim it, it is not a value. Test: would a competitor say the opposite? If not, dig deeper. |
| Not testing the firing question | "Would you fire someone for violating this, even if they're performing well?" — that is your real value test. If the answer is no, it is an aspiration, not a value. |
| Values created in isolation | Founder writes values alone in a cabin. Team has no ownership. Values feel imposed, not discovered. Involve the team early. |
| Values as wall posters, not daily behaviors | Values must show up in feedback, hiring, and decisions. If you cannot point to a decision that was changed by a value, the value is not real. |
| Too many values | 3-5 is the sweet spot. More than 5 and people cannot remember them. Gumroad has 4. Simply Eloped has 5 (CACAO). |
| Copying another company's values | Gumroad's values work for Gumroad. Discover your own through the 5-question process. Stories must be yours. |
